# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

**IT Contact:** security@example.com

Include in your report:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes

You should receive a response within 48 hours.
We will keep you updated as we work to address the issue.

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest  | Yes       |

## Security Standards

This project follows the security practices documented in `CLAUDE.md`.
All contributors must follow the security checklist before merging any PR.
