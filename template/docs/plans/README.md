# Plans

Implementation plans generated by `/create-plan` before coding begins.

## Usage

Run `/create-plan` in Claude Code to generate a plan for a feature or task.
Save the output here as `[feature-name].md` before starting implementation.

## Naming Convention

```
docs/plans/
├── user-authentication.md
├── billing-integration.md
└── search-refactor.md
```

## Committing Plans

Committing plans is optional but recommended — linking a plan in a PR description
gives reviewers context on the original intent and the tradeoffs considered.

To exclude plans from git, add this to .gitignore:
    docs/plans/*.md
    !docs/plans/README.md
